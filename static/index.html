封装全部 10 个接口 · 签名鉴权自动处理 · 点击即可调用

📁 文件管理
🔍 预上传审核
📤 正式上传
POST 获取文件列表 get_file_list
浏览开发者本人云盘目录，选取待上传的 fileId
🏠 根目录
POST 获取文件详情 get_file_detail
按 fileId 查询单个文件/目录详情，确认资源后再送审或上传
POST 文件/文件夹重命名 rename
修改开发者本人云盘内某文件/文件夹的名称
POST 预上传 pre_upload
将待上传的根文件/目录提交分享风控送审。建议正式上传前先走本接口
POST 预上传状态查询 pre_upload_status
轮询预上传任务整体进度，直至 status=3（完成）或 4（失败）
POST 预上传详情获取 pre_upload_detail
分页查看叶子文件审核结果（通过/拒绝/待审），用于排查 rejected/skipped
POST 通过文件ID上传 upload_by_fileid
正式发起跨用户 copy：将开发者云盘中的文件写入接收方 TOKEN 目录
POST 上传状态查询 upload_status
轮询正式上传任务，直到 success/failed
POST 上传跳过的文件列表 upload_skipped_list
终态后，查询上传跳过的文件列表（保留72h）
POST 上传成功的文件列表 upload_success_list
终态后，查询上传成功的文件列表（保留72h）
